# Dataset attribution

Vocabulary structure in this package was generated from the open HSK 3.0 dataset:

- Repository: `ivankra/hsk30`
- File: `hsk30.csv`
- Repository license: MIT
- Primary source referenced by that repository: PRC Ministry of Education HSK 3.0 standard

The dataset includes Hanzi, Traditional Chinese, Pinyin, part of speech, and HSK band.

English and Myanmar meanings are intentionally left blank in this package because the selected source file does not provide definitions. This prevents invented or incorrectly matched translations from being presented as authoritative.
